哲思卡片 · 安装说明
========================

【1】安装
把「哲思卡片.app」拖进「应用程序」文件夹。

【2】第一次打开被系统拦住
这个 App 没有 Apple 开发者签名和公证，macOS 会提示"无法验证开发者"。
任选一种放行：
  · 在 Finder 里按住 Control 点 App 图标 →「打开」→ 再点「打开」；
  · 或者：打开 App 一次（会被拦住）→ 系统设置 → 隐私与安全性 →
    页面下方点「仍要打开」→ 输入密码。
之后就可以正常双击打开了。

【3】先能用（不需要 API Key）
第一次启动会自动弹出第一张卡片，一共 65 张本地概念，离线也能用。
快捷键：⌥⌘K 呼出 / 隐藏。

【4】开启 AI 无限卡片（可选）
1. 点卡片底部的「✦ AI 设置」（或右键菜单栏图标 →「AI 设置…」）。
2. 粘贴你自己的 DeepSeek API Key。
3. 点「保存并启用」；想确认能不能用，点「测试连接」。
4. 之后读到牌组后段时，会自动在后台生成新卡片，并插进接下来几张里。

Key 只保存在这台电脑上：
  ~/Library/Application Support/PhilosophyCards/settings.json
（文件权限 600，只用于请求 api.deepseek.com，不会发给别处。）

【5】退出
⌘Q，或右键 Dock 图标 →「退出哲思卡片」，或设置页最下方「退出」。
右上角 × 只是收起面板，不是退出。

【6】系统要求
macOS 13 或更高，Intel / Apple Silicon 都可以。

【7】其他
· 收藏、AI 生成的卡片都只存在本机，换电脑不会同步。
· 设置页可以切换模型（V4 Pro 更稳 / Flash 更快），也可以清空 AI 卡片。
· 完全没有 Key 也能一直用本地 65 张卡片。
